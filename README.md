# taihei.dev

The website of the Taihei Framework, served by GitHub Pages from `main` with the custom domain in
`CNAME`. Plain HTML and one stylesheet: no build step, no JavaScript, no cookies, and nothing
loaded from other sites (the fonts are in `assets/fonts/`, under the SIL Open Font License).

- `/` the family, the story and the rules
- `/i18n/` taihei-i18n
- `/machiwari/` Machiwari, the commercial product built on the framework
- `/legal/` publisher, trademarks, licences and privacy

The brand (crest, colours, type) is in
[taiheiframework/.github/brand](https://github.com/taiheiframework/.github/tree/main/brand).
Preview locally with `python3 -m http.server -d . 8000`.
