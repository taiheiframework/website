Library, 4.x line

i18n

taihei-i18n is the 4.x line of Taihei Tsuji. From 5.0.0 the library is published as dev.taihei::taihei-tsuji, in the package dev.taihei.tsuji.

4.0.2 on Maven Central

Supported until

The 4.x line keeps its name, dev.taihei::taihei-i18n, and its package, dev.taihei.i18n. It receives security fixes for 12 months after the release of Taihei Tsuji 5.0.0, from branch 4.0.x of the tsuji repository. New work happens in Taihei Tsuji only.

// Mill
mvn"dev.taihei::taihei-i18n:4.0.2"

// sbt
libraryDependencies += "dev.taihei" %% "taihei-i18n" % "4.0.2"

Do not stay on 4.0.1 or earlier: see advisory GHSA-45w8-x6c8-w4hg and advisory GHSA-6h29-v54g-8337.

Moving to Taihei Tsuji

Taihei Tsuji 5.0.0 is the successor of taihei-i18n 4.x. Moving to it starts with the new coordinates and a change of imports from dev.taihei.i18n to dev.taihei.tsuji; the 4.x Message stays, deprecated, as dev.taihei.tsuji.legacy.Message until 6.0.0. The JSON of a message does not change, so a 4.x peer and a 5.x peer still exchange messages.
